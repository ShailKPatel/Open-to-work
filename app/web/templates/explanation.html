How it works

How Open to Work is built

It reads your GitHub and your resume, learns what you can actually do, and writes a resume tailored to one job posting. It runs on your machine in Docker; only the LLM call leaves it.

Every LLM call goes through one gateway

No feature calls a provider directly. Each call passes the same checks in order, so caching and spend limits can't be skipped. Switching provider is a setting.

Runs with one command

No Python, Node or GPU drivers needed on the host. Docker Compose starts two containers and keeps data in volumes, so it survives restarts.
